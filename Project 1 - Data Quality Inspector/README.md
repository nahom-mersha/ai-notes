# Data Quality Inspector

Notes from Project 1 of my AI engineering roadmap.

This project includes a Python command-line tool that inspects CSV datasets before machine-learning work. The tool identifies common data-quality problems and generates Markdown and HTML reports.

- Project repository: https://github.com/nahom-mersha/data-quality-inspector

## AI assistance

I used ChatGPT to help generate and explain code; I directed the work, reviewed the implementation, tested it, asked questions, and documented what I learned.

## What the project covers

- CSV inspection with Pandas
- Missing values, duplicates, constant columns, and suspicious values
- YAML-based validation
- Manual descriptive statistics and NumPy
- Scaling and train-test splitting
- Outliers, class imbalance, correlations, leakage, and category consistency
- Markdown and HTML reports
- SQL equivalents for data inspection
- Testing, configuration, and logging
