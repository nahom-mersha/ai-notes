# Project 0 - Reusable AI Project Template

## Goal

The goal of Project 0 was not to build an AI model. The goal was to build a reusable Python project template that I can use as the starting point for all my future AI projects.

Instead of creating the same project structure every time, I now have a professional template that already includes testing, formatting, linting, logging, configuration, CI, and Docker.

This project taught me how professional Python projects are organized before I start building actual AI applications.
