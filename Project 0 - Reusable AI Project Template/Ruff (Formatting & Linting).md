# Ruff (Formatting & Linting)

## Formatting

Formatting changes only the appearance of the code.

Everyone on the project ends up using the same coding style.

Example:

```bash
ruff format .
```

---

## Linting

Linting looks for potential problems.

Examples:

- unused imports
- unnecessary variables
- possible mistakes
- style problems

Example:

```bash
ruff check .
```

Formatting makes the code look better.

Linting helps make the code better.
